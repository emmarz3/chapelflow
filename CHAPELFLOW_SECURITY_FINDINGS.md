## Controls visible in source

- Production refuses known development signing keys, sets `DEBUG=False`, and enables HTTPS redirect, HSTS, secure/HTTP-only session cookies, nosniff and frame denial.
- REST API defaults to `IsAuthenticated`; public authentication endpoints explicitly declare `AllowAny`; scoped throttles are configured globally.
- JWT access lifetime is 15 minutes by default, refresh lifetime 7 days, with rotation and blacklist enabled.
- Password validators, request-ID middleware, audit context middleware, role permission helpers and branch scoping are present.
- Notification list is filtered to the current recipient; report task rechecks branch access; attendance QR tokens are signed and expire.

Source presence does not establish that provider settings are correct or that each endpoint is covered by tests. No live environment or destructive test was used. Phase 1 source work and local verification completed on 2026-11-05: focused backend security tests passed (189 passed, 1 skipped), frontend tests passed (125 passed), the production build succeeded, and `python manage.py check` reported no issues. Provider-side identification of the deployed origin/settings and verification/revocation of previously public exports remains a deployment launch gate under Phase 9. Phase 2 review has identified a staff-only prayer-note exposure through the member prayer-request serializer; remediation and regression coverage are in progress.
