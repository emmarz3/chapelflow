# Public Static Assets

This directory contains static assets served directly by the frontend.

## Contents

- Images used in the frontend (hero images, slides, branding, etc.)
- The generated campus-chapel hero image (`chapel-hero.png` and `chapel-hero.jpg`)
- Authentication visuals (for email templates, etc.)

## Note

Images are optimized for web use. The chapel-hero images are generated during deployment and should be replaced with approved institutional photography when available.
